# COURSE DESCRIPTION
This course introduces the fundamental concepts of digital systems, including Boolean algebra, logic gates, and combinational and sequential circuit design.

# COURSE OUTCOMES
* K2 - Describe the fundamental principles of Boolean algebra and logic gates.
* K3 - Apply minimization techniques to simplify complex Boolean expressions.
* K4 - Design and analyze combinational logic circuits like adders and multiplexers.
* K4 - Analyze the behavior of flip-flops and sequential logic elements.
* K6 - Construct a simple digital counter system to meet specific timing requirements.

# UNIT 1 (9 Hours)
## Number Systems and Boolean Algebra
* Binary, Octal, and Hexadecimal number systems.
* Logic Gates: AND, OR, NOT, NAND, NOR, XOR, XNOR.
* Boolean laws and De Morgan’s theorems.
* Minimization using Karnaugh Maps (up to 4 variables).

# UNIT 2 (9 Hours)
## Combinational Logic Design
* Design of Adders and Subtractors.
* Multiplexers and De-multiplexers.
* Encoders and Decoders.
* Magnitude Comparators and Code converters.

# UNIT 3 (9 Hours)
## Sequential Logic Fundamentals
* Latches and Flip-Flops: SR, JK, D, and T.
* Triggering and Excitation tables.
* Analysis of Clocked Sequential Circuits.
* Shift Registers: SISO, SIPO, PISO, PIPO.

# UNIT 4 (9 Hours)
## Counters and Design
* Asynchronous (Ripple) Counters.
* Synchronous Counters: Up/Down and Ring counters.
* Design of Modulo-N counters.
* State diagram and State reduction.

# UNIT 5 (9 Hours)
## Digital Integrated Circuits
* Logic Families: TTL, CMOS, and ECL characteristics.
* Programmable Logic Devices (PLD): PROM, PLA, PAL.
* Field Programmable Gate Arrays (FPGA) overview.
* Memory organization: RAM and ROM.
